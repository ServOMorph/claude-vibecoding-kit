# Ouvrir une application Windows

Macro générique d'ouverture, utilisée par défaut pour toute application cible.

## Séquence

1. Appuyer sur la touche `Windows`.
2. Saisir exactement le nom de l'application demandée.
3. Appuyer sur `Entrée`.

## Règle

Cette séquence s'applique à toute application, sauf lorsqu'une macro ou une instruction explicite définit une autre méthode d'ouverture.
