# Journal de contrôle

`control.log` est créé au lancement du halo. Chaque action significative y ajoute une ligne :

```text
[AAAA-MM-JJ HH:MM:SS] <événement factuel>
```

Le halo relit ce fichier en continu. Les nouvelles lignes sont affichées immédiatement dans la barre basse, puis les lignes antérieures défilent.

Ne jamais y écrire de contenu personnel affiché dans une application ; décrire uniquement l’action et son résultat.
